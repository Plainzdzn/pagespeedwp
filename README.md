# WebP-Umwandler

WordPress-Plugin von Akuma Digital. Ersetzt PNG- und JPG-Bilder in der Mediathek durch WebP, mit derselben Attachment-ID, und zieht alle Verweise in der Datenbank mit. Danach kann das Plugin entfernt werden, der Zustand bleibt.

**Stand:** in Entwicklung (M1: Grundgerüst, Seiten, Systemprüfung). Noch keine Umwandlung. Nicht auf Live-Seiten einsetzen.
